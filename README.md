# 💼 Hanif Daffa Dzulfahmi - React Portfolio

> Pioneering Future Technical Innovations - IT Student & Network Enthusiast

Built with **React 19**, **TypeScript**, **Vite**, **Three.js**, and modern CSS glassmorphism architecture.

## ✨ Features

### 🎨 Design & Effects
- **Glassmorphism Aesthetic** - Frosted glass cards with backdrop blur
- **3D Three.js Starfield Background** - Dual-layer particle universe with responsive resize
- **Interactive 3D ID Card** - Real-time mouse tilt parallax with holographic glow border
- **Skill Galaxy Orbit System** - Dynamic CSS orbit simulation tracking technical domains
- **Custom Cursor** - Ring and dot with smooth interpolation and element reaction
- **Scroll Progress** - Real-time scroll indicator bar

### 🌐 Multilingual System
- 🇬🇧 **English (Professional)**
- 🇮🇩 **Bahasa Indonesia (Native)**
- 🇯🇵 **Japanese (日本語 - Learning)**
- Seamless instant language switching across all sections, modals, and navigation.

### 🚀 Interactive Experience
- ⌨️ **Command Palette (`Ctrl+K` / `Cmd+K`)** - Quick search, section jump, and language switching
- 🎬 **Cinematic Intro** - Multilingual animated welcome sequence with progress bar
- 🔍 **Project Showcase & Modal** - Filterable project gallery (Networking, Web Dev, IT Admin) with deep dive problem/solution views
- 📊 **Animated Stats Counter** - Number count-up trigger on scroll or intro completion
- 📱 **Fully Responsive** - Mobile-first layout with desktop optimizations

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler & Dev Server**: Vite
- **3D Graphics**: Three.js
- **Icons**: Lucide React + custom SVGs
- **Typography**: Syne, DM Sans, Noto Sans JP

## 🚀 Running the App

```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
```
